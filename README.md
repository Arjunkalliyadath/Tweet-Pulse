# Twitter/X Sentiment Analyzer

A sentiment analysis dashboard built using:

- Playwright
- FastAPI
- HuggingFace Transformers
- Pandas

## Features

- Extract comments from X/Twitter posts
- Sentiment classification using RoBERTa
- Dashboard visualization
- Positive, Neutral and Negative sentiment analysis

## Tech Stack

- Python
- FastAPI
- Playwright
- HuggingFace
- HTML/CSS
